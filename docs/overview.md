# TerraNova Overview

TerraNova is an offline tool for building Hytale World Generation V2 asset packs. It provides:

- A **node-based editor** for creating density graphs, materials, and environment assets.
- A **live preview** with voxel rendering, heightmaps, and material overlays.
- Support for **Hytale-native JSON formats** (biomes, environments, weather, world structures).
- Tools to import/export from the official Hytale asset format, including canvas comments and frames from `$NodeEditorMetadata`.
- **Release install asset sync** from `Assets.zip` (with pre-release as an alternate Settings channel).

This docs site is organized into sections:

- **Getting Started**: Quickstart guides to create your first pack.
- **Walkthroughs**: Step-by-step tutorials for real features.
- **Reference**: Node and format documentation.
