# Getting Started with TerraNova

This guide walks you through the first steps after launching TerraNova.

## 1) Launching the app

- On desktop, open the TerraNova application. If you're running from source, use `pnpm dev` in the `TerraNova-fork` folder.

## 2) Opening a World

- Use **File → Open** or the **Open World** button to load an existing `.world` file.
- Use the **New World** button to create a new world from scratch or from a template.

## 3) Key Concepts

- **Nodes**: The building blocks of world generation. Each node represents a generator, filter, or transform.
- **Biomes**: Collections of nodes that describe how terrain, vegetation, and atmosphere should look.
- **Terrain Systems**: Groups of nodes that define the shape of the terrain.
