# Walkthrough: Create a World

This walkthrough shows a simple flow for creating a new world in TerraNova.

## Step 1 — New World

1. Click **File → New World**.
2. Choose a template (e.g., "Starter Island") or start blank.

## Step 2 — Open the Node Editor

1. Once the world is created, open the **Node Editor** panel.
2. Select any node to inspect its properties.

## Step 3 — Generate Terrain

1. Add a terrain generator node (e.g., Perlin noise).
2. Hook it into the world’s height map output.
3. Click **Generate** to preview.

## Step 4 — Save Your World

- Use **File → Save** to persist your work.
- The world file is saved as `.world` in your chosen folder.

---

> Tip: Use the **Help** toggle in the property panel to see field-specific guidance.
